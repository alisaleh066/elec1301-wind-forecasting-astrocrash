# elec1301-wind-forecasting-astrocrash

ELEC1301 mini-project: (1) wind-generation analytics and ARIMA forecasting (`src/wind_forecasting.py`), (2) Astrocrash, a Pygame game refactor (`src/astrocrash.py`).

## Commands
`pip install -r requirements.txt` · `python src/wind_forecasting.py` · `python src/astrocrash.py`

## Rules
- Use a conda env (or `.venv`); do not install into base.
- Keep raw data in `data/` unmodified; write generated plots to `outputs/`.
- Coursework: do not rewrite the report in `reports/` without being asked.
